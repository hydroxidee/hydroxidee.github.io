# Portfolio Template

## Getting Started 🚀

### Local Setup
1. Keep all files in the same directory
2. Open `index.html` in a web browser to view your portfolio

### Files Overview
- `index.html`: Main HTML file containing your portfolio content
- `styles.css`: Custom styles and animations
- `tailwind.js`: Tailwind CSS framework for styling
- `lucide.min.js`: Lucide icon library



## Need Help? 
Check out https://portloom.com/?page=help

### Hosting Options
You can host your portfolio for free on:
- GitHub Pages (recommended!)
- Netlify
- Vercel
- Or any other web hosting service

### Customization
- Edit `index.html` to update content (text, links, etc.)
- Edit `styles.css` to modify styles and animations
